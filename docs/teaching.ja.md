# Rythme で教える

*[English version →](teaching.md) · [Version française →](enseigner.md) · [En español →](teaching.es.md) · [Auf Deutsch →](teaching.de.md) · [Em português →](teaching.pt.md) · [中文 →](teaching.zh.md) · [In italiano →](teaching.it.md)*

Rythme は教室のために設計されました。小さな言語と教えてくれるメッセージによって、学生は構文ではなく考え方に時間を使えます。このガイドでは、授業に必要なものを扱います：授業計画、自動でチェック・採点される練習問題、コードの動きを見せる方法、そして AI アシスタントについてのルールです。

## 授業に向いている理由

- **本物のプログラムを書くまでに覚えることが少ない。** キーワードは 15 個、関数の定義の仕方は 1 つ、選び方も 1 つ（`if`/`match`）で、クラスもループもミューテーションもありません。構文のすべてを 1 ページで読めます（`rythme help syntax`）。
- **インタープリターがティーチングアシスタントになる。** エラーは正確な場所を指し、問題を説明し、修正を提案します。他の言語から持ち込んだ誤り（`for`、`return`、`x += 1`、`null` など）には、関数型のやり方が説明されます。`rythme explain E0xx` は例を添えた詳しい説明を示します。`rythme check` はプログラムを実行せずに問題を見つけ、`"年齢：" + 36` のように必ず失敗する操作も見つけます。
- **初日から関数型で考える。** 不変性、値としての関数、再帰、パターンマッチング、代数的データ型、値としてのエラー（`Option`、`Result`）：Haskell、OCaml、Elm、Elixir、Rust の概念を、その構文も、初日から格闘する型システムもなしに学べます。型は省略できます：チェッカーが自分で見つけ、授業がそこまで進んだら学生が型を書き（`fn area(w: Int, h: Int) -> Int`、`type Tree(a)`）、チェッカーがそれを確かめます。
- **テストが組み込まれている。** コードのそばに `test "..." = assert_eq(actual, expected)` を書き、`rythme test file.ry` で実行します。練習問題にテストを付けて配れます。
- **学生になじみのあるライブラリ。** テキスト、リスト、辞書、日付、CSV、正規表現、そして機械学習の単元のためのベクトル、統計、傾き（`rythme help ml`）。Ruby や Python を知っている学生は、多くの関数を知っている名前で見つけられます（`upcase`、`strip`、`each_slice` など）：`rythme help ruby` と[ライブラリの比較](stdlib-audit.md)（英語）を参照してください。
- **学生の言語で**、しかも**インストールが簡単で、無料で、オープン**：依存関係のない 1 つのプログラムで、MIT ライセンス、Linux、macOS、Windows に対応。Web サイトのプレイグラウンドなら何もインストールせずに使えます。

## 自動でチェックされる練習問題

テストを書き終えたファイルを学生に渡し、書くべき関数はそれぞれ `fail("未完成")` にしておきます。次は学生が仕上げたもので、よくある誤りがあります：

```rythme
## 空でないリストのいちばん大きい要素を返す。
fn largest(list) = fold(list, 0, max)

test "要素が 1 つ" = assert_eq(largest([7]), 7)
test "複数の要素" = assert_eq(largest([3, 9, 2]), 9)
test "負の数" = assert_eq(largest([-3, -1, -2]), -1)
```

`rythme test largest.ry` は何が成功したかを伝え、失敗ごとに期待した値と得られた値を示します：

```text
3 個のテストを実行中
  ✓ 要素が 1 つ
  ✓ 複数の要素
  ✗ 負の数
エラー[E015]: アサーション失敗：値が違う
 --> largest.ry:6:14
  |
6 | test "負の数" = assert_eq(largest([-3, -1, -2]), -1)
  |                 ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  |
  = note: 得られた値：0
      期待した値：-1
  = このエラーについて詳しく：`rythme explain E015`

3 個のテスト：成功 2、失敗 1 (1 ms)
```

このような練習問題が 36 問用意されています：[**練習問題**](exercises/README.md)は ★☆☆ から ★★★ まで段階的で、上の授業計画に沿っており、それぞれに問題、ヒント、テストがあり、メッセージのどの言語でも使え、教師向けの参考解答も付いています。`rythme` に組み込まれています：

```sh
rythme exercise list                     # 練習問題の一覧
rythme exercise start 7                  # 07-recursion.ry を現在のフォルダーにコピーする
rythme exercise check 07-recursion.ry    # テストを実行し、アドバイスを添えて次の問題を提案する
```

`rythme exercise check` は、組み込みの練習問題のテストが変更されたことも伝えます：練習問題が解けたことになるのは、元のテストが成功したときだけです。自分で作る練習問題も同じ形にできます（コメントに問題とヒント、関数に `fail("未完成")`、`# --- テスト（変更しないでください）---` の行の後にテスト）。`rythme exercise check` はテストのあるどのファイルにも使えます。

## `--format json` で採点する

`rythme test` はフォルダーを受け付けます：学生ごとに 1 つのファイル（またはフォルダー）にすれば、1 つのコマンドでクラス全員のテストを実行できます。

```sh
rythme test --sandbox --format json submissions/ > results.json
```

- **`--format json`** は、人向けのメッセージの代わりに 1 つの JSON 文書を出力します：ファイルごとに `tests`、`failed`、`broken`（コンパイルできない、またはテストの前に止まるファイル）、テストごとに `name`、`file`、`passed`、`failure`、最後に `summary`。キーは決して変わりません（[スキーマ](rythme-output.schema.json)）。メッセージは `--lang` に従います。
- **`--sandbox`** はプログラムをファイル、フォルダー、環境変数、ネットワークから遠ざけます。時間の制限はないので、制限付きでコマンドを実行してください（Linux なら `timeout 60 rythme test ...`）。
- **学生は自分のファイルのテストを変更できます。** 採点には自分のコピーを実行してください：`rythme exercise check` は組み込みの練習問題のテストが変更されたことを伝えますが、参考解答は（リポジトリで）公開されています。採点する課題には、自分で作った練習問題を使ってください。
- `rythme check --format json` は警告を加えます。それぞれに固定のコードがあります（W001 使われていない名前、W002 忘れたケースなど）。`rythme fmt --check` はコードが公式のレイアウトかどうかを伝えます。

Rythme は自分で JSON を読めます。次のプログラムは結果を点数に変えます：

```rythme
# grades.ry
fn grade(f) = if f.broken then "{f.file}：動かない" else "{f.file}：{f.tests - f.failed}/{f.tests}"

results = read_file(args()[0]) |> unwrap |> parse_json |> unwrap
each(results.files, fn(f) = print(grade(f)))
```

`rythme grades.ry results.json` の表示：

```text
submissions/ada.ry：3/3
submissions/alan.ry：2/3
submissions/grace.ry：動かない
```

## コードの動きを見せる

`rythme steps` は置き換えモデルで計算を 1 ステップずつ見せます：各呼び出しはその関数の本体に置き換えられ、最後には結果だけが残ります。再帰、累積引数、末尾呼び出しが目に見えるようになります。

```rythme
fn fib(n) = if n < 2 then n else fib(n - 1) + fib(n - 2)

fib(4)
```

`rythme steps fib.ry` の表示：

```text
fib(4)
  → fib(3) + fib(2)
  → fib(2) + fib(1) + fib(2)
  → fib(1) + fib(0) + fib(1) + fib(2)
  → 1 + fib(0) + fib(1) + fib(2)
  → 1 + 0 + fib(1) + fib(2)
  → 1 + fib(1) + fib(2)
  → 1 + 1 + fib(2)
  → 2 + fib(2)
  → 2 + (fib(1) + fib(0))
  → 2 + (1 + fib(0))
  → 2 + (1 + 0)
  → 2 + 1
  → 3
```

`rythme steps fib.ry "fib(6)"` は別の式を、`:steps fib(6)` は対話モードで同じことを見せます。プレイグラウンドの**ステップ**ボタンも同じで、*共有*を使えば同じステップで開くリンクを作れます：プロジェクターに映したり、クラスに送ったりするリンクが 1 つで済みます。

`rythme debug file.ry` は指定した場所（`break 12`、`break fib`）でプログラムを一時停止し、名前の値を表示します。`where` は実行中の呼び出しをその引数とともに一覧し、同じ関数の呼び出しがいくつ待っているかを伝えます：再帰のスタックをその場で見られます。末尾位置の呼び出しは、呼び出し元の場所を引き継いだことを伝えます。VS Code では `.ry` ファイルで `F5` を押すと同じデバッガーが起動し、余白にブレークポイントを置けます。[マニュアル](reference.md#79-the-debugger-rythme-debug)（英語）にセッション全体の例があります。

## 何もインストールせずに：プレイグラウンド

[Web サイト](https://maxlestage.github.io/Rythme/)のプレイグラウンドは、本物のインタープリターをブラウザーで同じメッセージとヘルプとともに動かします：学生はどのコンピューター、タブレット、スマートフォンでも始められます。

- **実行**、**チェック**、**テスト**、**整形**、**ステップ**はコマンドと同じように動きます。練習問題を貼り付けて**テスト**を押してください。
- **共有**はプログラムそのものを含むリンクを作ります（サーバーには何も送りません）：出発点や授業のプログラムを配れます。**シード**を使えば、学生全員の `random` の結果を同じにできます。
- アプリとしてインストールすると（メニューの**アプリをインストール**、または iPhone と iPad では*ホーム画面に追加*）、サイトとプレイグラウンドはオフラインで動くので、ネットワークの弱い教室で役立ちます。書いているコードはブラウザーに残ります。
- ブラウザーではファイルを読み書きできず、`input()` は空のテキストを返し、入れ子の呼び出しは 600 で止まります（末尾呼び出しに制限はありません）。

## 学生の言語で

- どのメッセージ、ヘルプのトピック、説明、`rythme learn` のページも、英語、フランス語、スペイン語、ドイツ語、ポルトガル語、中国語、イタリア語、日本語でそろっています。Rythme はシステムの言語に従い、`--lang ja` や環境変数 `RYTHME_LANG=ja` で別の言語を選べます。
- キーワード、関数の名前、コマンドはどの言語でも同じです：あるクラスで書いたプログラムはどこでも動き、`rythme help` はどの言語のトピック名も受け付けます（`rythme help リスト`）。
- 練習問題も言語に従います：`rythme --lang de exercise start 7` はドイツ語で `07-rekursion.ry` を書きます。
- Web サイト、そのプレイグラウンド、このガイドも同じ言語でそろっています。

## 授業での AI アシスタント

学生の手元にはアシスタントがあります。Rythme はそれを見破ろうとはしません。ここでは Rythme が提供するものと、授業に合わせて変えられるルールを示します。

**Rythme が提供するもの。** アシスタントは Rythme ができる前に訓練されました：そのままでは Python や JavaScript の習慣（`for`、`return`、`x += 1`）を書き、Rythme はそれを、何を書けばよいかを伝えるメッセージとともに拒否します。言語全体を 1 つのテキストにした `rythme help llms`（Web サイトの *AI* ページにもあります）を渡せば、正しい Rythme を書きます。`rythme mcp` を使うと、アシスタントは自分でコードをサンドボックスで実行し、チェックし、テストできます。プレイグラウンドの *AI 用にコピー* は、プログラムとその出力またはエラーを、チャットにすぐ使える形でコピーします。`rythme fix` は確実な修正（`&&` → `and`、`let x = 3` → `x = 3`）を適用し、`rythme fix --dry-run` はそれを表示するだけです。

**ルールの例。**

- **最初の数週間：コードは学生が書く。** 目的は反射的に書ける力を身につけることで、メッセージと `rythme explain` がすでに一つひとつの誤りを説明しています。アシスタントはメッセージや考え方を説明してよいですが、解答を書いてはいけません。
- **メッセージを読んでから `rythme fix`**：確実なもの、つまりメッセージが提案するのと同じ修正だけを変えます。
- **プロジェクト：使ってよいが、申告する。** アシスタントに `rythme help llms` を渡し、学生には何に使ったかを申告させ、自分のコードを説明させます。
- **結果だけでなく理解を評価する。** テストはプログラムが動くことを確かめますが、だれが書いたかは確かめません。授業中の短い確認を加えましょう：コンピューターなしで `rythme steps` のステップ、プログラムの出力、メッセージの修正を予想する。あるいはプレイグラウンドでその場で練習問題を解く。
- **自分の仕事には**、`rythme help llms` を渡したアシスタントが上の形式で新しい練習問題の下書きを作れます。配る前に、自分の解答と `rythme test` で一つひとつ確かめてください。

## 実践的なヒント

- 対話モード（`rythme`）から始めましょう：どの行もその値を表示します。`:doc map` は関数のドキュメントを表示し、Tab キーで名前を補完できます。
- `rythme learn` は学生が一人で進められるガイドツアーです。
- `rythme help builtins` はすべての組み込み関数を分類して一覧し、どのコマンドも `--help` に答えます（`rythme test --help`）。`rythme completions bash`（または `zsh`、`fish`、`powershell`）でターミナルでのコマンドの補完ができます。
- [VS Code 拡張機能](../editors/vscode)をインストールしましょう：色分け、スニペット、入力中に表示される問題とそのクイックフィックス、マウスを重ねたときのドキュメント、デバッガー。他のエディターも言語サーバーを使えます（[`editors/README.md`](../editors/README.md)）。
- `rythme fmt` はどのファイルも同じレイアウトにします：学生は提出前にそれ（または `rythme fmt --check .`）を実行できます。
- 大きめのプロジェクトには、`rythme new NAME` が `src/`、`tests/`、`rythme.toml` のあるフォルダーを作ります。そうすると `rythme test` だけでプロジェクトのすべてのテストが実行され、`rythme add` で[パッケージインデックス](reference.md#711-the-package-index)のパッケージを加えられます。
